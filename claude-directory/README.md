# Ploten for Claude Code

Claude Code edits the Power BI report you have open in Power BI Desktop. Each change shows on the canvas while Desktop stays open, so you do not save, close or reload the report.

This plugin holds one skill and no program. When Ploten is not on your PC yet, the skill shows Claude what Ploten needs and the steps you take to install it. When Ploten is installed, the skill steps aside.

Ploten runs on your Windows PC, next to Power BI Desktop. Ploten is a paid program. Free to try for 14 days.
